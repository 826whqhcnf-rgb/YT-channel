# Background music

Drop a royalty-free track here named `bg.mp3` (the path in `config.yaml`).

Only use music you are licensed to use. Good free sources:

- YouTube Audio Library (https://studio.youtube.com → Audio Library) — free, many tracks cleared for monetization.
- Pixabay Music (https://pixabay.com/music/) — free for commercial use, no attribution.
- Free Music Archive (https://freemusicarchive.org) — check each track's license.

If no file is present, the pipeline simply renders narration without music.
